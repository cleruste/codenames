Un mot peut tout relier.

  1. Formez deux équipes, rouge et bleue, avec un maître-espion par équipe. L’équipe indiquée commence avec neuf agents ; l’autre en a huit.
  2. Posez la tablette au centre. Chaque maître-espion ouvre cette même adresse sur son téléphone, saisit le code de la tablette et active « Afficher les couleurs », à l’abri des regards.
  3. À tour de rôle, le maître-espion donne à voix haute un seul mot et un nombre pour relier des agents de sa couleur. Son équipe peut proposer jusqu’à ce nombre de mots, plus un.
  4. Double-touchez ou double-cliquez un mot sur la tablette pour le révéler. Au clavier, sélectionnez la carte avec Tab, puis Entrée ou Espace. Un agent adverse ou un neutre termine votre tour ; vous pouvez aussi passer oralement.
  5. La première équipe dont tous les agents sont révélés gagne. L’assassin met immédiatement fin à la partie. Les tours et indices ne sont pas suivis par l’application.

Le code partage uniquement la grille initiale. Les choix, compteurs et annulations ne se synchronisent pas. Une nouvelle partie exige de saisir le nouveau code sur les téléphones.

La clé reste dans le navigateur : elle est discrète, mais ne protège pas contre la triche. Le mode couleurs bloque les révélations et annulations accidentelles.
